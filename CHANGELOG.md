# Changelog

All notable changes to HypeRate for Unreal Engine are documented here.

## [1.0.0-pre.1] - 2026-11-06

### Added

- Blueprint and C++ HypeRate client Actor Component.
- Phoenix join, leave, heartbeat, heart-rate parsing, and automatic reconnect.
- Game-thread connection, state, heart-rate, disconnect, and error events.
- Local per-user Editor test settings and Tools menu entry.
- Resting, Workout, Intense, and Custom simulation profiles.
- Native UMG/Slate BPM widget with history graph and state colors.
- Unreal Automation protocol and simulation tests.
- GitHub validation plus source and Fab package release tooling.
- Illustrated Editor setup and simulation screenshots.
- Step-by-step Unreal testing guide for Blueprint, live data, widget, and
  Automation Test verification.
- Gameplay use cases, signal-flow diagram, and Blueprint/C++ BPM-to-intensity
  example in the GitHub documentation.

### Changed

- Fresh Editor settings now leave the Device/Session ID empty instead of using
  an internal development value.
